# pressure-test · Phase 01: Competitors and Flywheel

## Phase context

Individual deliverable, sections: **The market · Ten competitors · The biggest one · Its flywheel** (drawing, loop in words, what slows it down, where my hypothesis sits). Also read the student's phase 00 draft for the person and hypothesis the market should follow from.

## Checks (run all, in order)

### Market test
Is the market defined by a person and a job, or by an industry label? Quote the definition. If it's a label ("the funeral industry"), ask who is choosing and what they're trying to get done. Does it connect to the person in the phase 00 draft, or is it a different market?

### Same-customer test
For each of the ten: would the person in the market definition actually choose this instead? Output a table: competitor, the draft's direct/indirect label, and your reading: `direct`, `indirect`, or `not this customer's choice`. Don't remove anyone from the list; report.

### Count
Ten rows, each with a size signal and a source link? If fewer, or if signals are missing, say which.

### Biggest-by-what test
Is the measure stated? Is the number sourced, with year and scope? Would a different reasonable measure name a different company? If so, ask whether the chosen measure is the right one for this market.

### Loop test
Read the loop in words. Is it closed (the last arrow returns to the first node)? Does every arrow have a *because* that names a mechanism, not a restatement? Is it reinforcing (more leads to more) rather than a list of features with arrows? Three to seven nodes? Report each.

### "Any-company" test
Would this loop be equally true of any company in any industry ("more customers → more revenue → more marketing → more customers")? Quote the arrows that are generic and ask what's specific to this company: what does it get more of that a competitor the same size doesn't?

### Drawing check
Is there an image in the folder, embedded in the draft? Does it show the same nodes as the loop in words? If it's a Mermaid block only, say the image is still to do.

### Claim/source table
Every quantitative claim (size signals, the biggest-one number, any number on an arrow): the source it points to and a status: `supported`, `source doesn't say this`, `no source`, `stale` (roughly 2020 or earlier for size claims), `scope mismatch` (different measure, year, or geography). Output as a table.

### Break test
Does "What slows it down" name something that actually acts on a node in the loop? Or is it generic ("competition", "regulation")? If generic, ask which arrow it slows.

### Fit test
Does "Where my hypothesis sits" follow from the loop as drawn? Quote both. If the hypothesis would be hurt by the loop and the draft says it rides it, or the reverse, ask.

## Don't

- Don't propose competitors, measures, or nodes of your own.
- Don't redraw the loop; report what's missing.
- Don't comment on the drawing's looks, only on whether it matches the loop in words.

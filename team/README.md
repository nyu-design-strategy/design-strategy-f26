# team/

Group deliverables live here, one file per phase, plus the team's session log.

```
team/
├── 01-downselect.md    phase 01: the two hypotheses, the people, the recruiting plan
└── notes.md            what the team discussed and decided, written by /team
```

**How to work here.** One person opens the repo during the team meeting and runs `/team` (Claude Code) or `$team` (Codex). Everyone talks; that person types. The AI reads everyone's drafts, asks the team one question at a time, and writes the file in the team's words with names attached. It never ranks or picks for you.

**Submitting.** Any member runs `/submit` and says it's the team's submission. One PDF, one tag, one link in Slack per team.

**Decisions** also go in the decision log in `team.md`, so the whole semester's choices are in one place.

Don't edit this README; the course replaces it on every update.

# start (free chat path)

*You don't need to paste this into an AI. These are the setup steps for students working through the GitHub website instead of Claude Code or Codex.*

---

1. Open your team repo on github.com. It's called `ds-f26-g<your group number>`.
2. Read `team.md`. Your brief is there.
   Your folder name is your NetID plus your name, lowercase with hyphens: for example `ti2219-teo-ivancevic`.
3. Click **Add file → Create new file**. In the name box type:

   ```
   00-opportunity-hypothesis/<your-netid>-<your-name>/draft.md
   ```

   Typing the slashes creates the folders. In the file body, paste the contents of `course/templates/opportunity-hypothesis.md` (open it in another tab, click **Raw**, copy everything). Fill in the header line (name, NetID, group, topic) and paste your team's topic, secular waves, and challenge lines from `team.md` under **The Category**. Click **Commit changes**.
4. Create two more files the same way:

   ```
   00-opportunity-hypothesis/<your-netid>-<your-name>/notes.md        first line: # Notes · Your Name (netid)
   00-opportunity-hypothesis/<your-netid>-<your-name>/sessions/links.md   one line: share links go here
   ```

5. Edit `team.md` and add a row to the Members table with your name, NetID, and GitHub username.

You're set up. Next: open `course/chat-versions/office-hours.md`, copy all of it, paste it into a new chat with any AI, and answer its questions. When it gives you the notes entry at the end, append it to your `notes.md`. Paste the chat's share link into `sessions/links.md`.

## Phase 01 (Competitors and Flywheel)

Same steps, with a new folder next to your phase 00 one. Create `01-competitors-flywheel/<your-netid>-<your-name>/draft.md` (same folder name as before) and paste `course/templates/competitors-flywheel.md` into it; fill the header and the Category lines from `team.md`. Create `notes.md` in the same folder with the header line. Your drawing goes in that folder too, as `flywheel.png`. For the group tasks, one teammate uses `course/chat-versions/team.md` during your team meeting.

# start (free chat path)

*You don't need to paste this into an AI. These are the setup steps for students working through the GitHub website instead of Claude Code or Codex.*

---

1. Open your team repo on github.com. It's called `ds-f26-g<your group number>`.
2. Read `team.md`. Your brief is there.
3. Click **Add file → Create new file**. In the name box type:

   ```
   00-opportunity-hypothesis/<your-netid>/draft.md
   ```

   Typing the slashes creates the folders. In the file body, paste the contents of `course/templates/opportunity-hypothesis.md` (open it in another tab, click **Raw**, copy everything). Click **Commit changes**.
4. Create three more files the same way, each with a single line of text like `notes go here`:

   ```
   00-opportunity-hypothesis/<your-netid>/thinking/README.md
   00-opportunity-hypothesis/<your-netid>/review/README.md
   00-opportunity-hypothesis/<your-netid>/sessions/links.md
   ```

5. Edit `team.md` and add a row to the Members table with your name, NetID, and GitHub username.

You're set up. Next: open `course/chat-versions/office-hours.md`, copy all of it, paste it into a new chat with any AI, and answer its questions. When it gives you the notes file at the end, create it in your `thinking/` folder the same way as above. Paste the chat's share link into `sessions/links.md`.
